MNBSD-2026-93: Privilege escalation via TCP urgent data on read-only mbufs (CVE-2026-127748)

Severity: Unknown

Affected Package: kernel/tcp

Summary: Privilege escalation via TCP urgent data on read-only mbufs (CVE-2026-127748)

Description

TCP urgent data (out-of-band data, MSG_OOB) is a single byte that the receiver can read separately from the normal data stream. When it arrives, the kernel removes it from the received data. tcp_pulloutofband() in sys/netinet/tcp_input.c removed the urgent byte by moving the rest of the mbuf's data over it, assuming the mbuf could be modified. That is not always the case. For example, data sent with sendfile(2) over a local connection is carried in mbufs that reference shared file pages. A local user can use urgent data to modify read-only memory, such as the cached pages of a file they can only read, and use this to obtain root privileges.

Affected Versions

kernel/tcp
