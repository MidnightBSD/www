MNBSD-2026-86: Use after free when detaching kqueue timers (CVE-2026-101320)

Severity: Unknown

Affected Package: kernel/kqueue

Summary: Use after free when detaching kqueue timers (CVE-2026-101320)

Description

kqueue(2) timers (EVFILT_TIMER) are implemented with callouts. When the process that owns a timer knote is stopped, its timers are kept on a per-process list and re-armed when the process continues. filt_timerdetach() in sys/kern/kern_event.c drained the timer's callout, removed the timer from the stopped-timers list, and repeated the drain if the callout had been re-armed in the meantime. Because softclock clears a callout's pending bit without holding the callout lock, a callout that fired during this check could be missed. It then ran after the timer data had been freed. A local user can exploit the resulting use after free to corrupt kernel memory and gain root privileges. The related FreeBSD issue in kqueue_fork_copy_list() (CVE-2026-127750, also part of FreeBSD-SA-26:85) does not affect MidnightBSD, which does not have that code.

Affected Versions

kernel/kqueue
