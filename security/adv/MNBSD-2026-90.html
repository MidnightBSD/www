MNBSD-2026-90: Use after free with largepage shared memory mappings (CVE-2026-127744)

Severity: Unknown

Affected Package: kernel/vm

Summary: Use after free with largepage shared memory mappings (CVE-2026-127744)

Description

Shared memory objects created with shm_create_largepage(3) are backed by large physical pages (for example 2 MB on amd64) and can be mapped into a process's address space with mmap(2). vm_map_pmap_enter() in sys/vm/vm_map.c, which pre-populates page tables for a new mapping, was not aware of largepage objects and entered their 4 KB constituent pages individually. A constituent page could then remain mapped in a process after the largepage object had been freed. A local user can keep access to physical memory that has been freed and reused by the kernel, and use this to escalate privileges.

Affected Versions

kernel/vm
