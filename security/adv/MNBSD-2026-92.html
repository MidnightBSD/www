MNBSD-2026-92: Missing access check for O_CREAT directory opens (CVE-2026-127746)

Severity: Unknown

Affected Package: kernel/vfs

Summary: Missing access check for O_CREAT directory opens (CVE-2026-127746)

Description

open(2) accepts O_CREAT together with O_DIRECTORY. Since open(2) cannot create directories, the combination opens an existing directory. vn_open_cred() in sys/kern/vfs_vnops.c handled O_CREAT with O_DIRECTORY as a plain lookup, but left O_CREAT set. vn_open_vnode() skips the access check for O_CREAT opens, assuming the file was just created by the caller, so the directory was opened without the read or search permission check. A local user can open a directory they have no read or search permission for, and read its entries.

Affected Versions

kernel/vfs
