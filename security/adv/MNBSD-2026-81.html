MNBSD-2026-81: Local privilege escalation via netlink heap buffer overflow (CVE-2026-127747)

Severity: Unknown

Affected Package: kernel/netlink

Summary: Local privilege escalation via netlink heap buffer overflow (CVE-2026-127747)

Description

netlink(4) is a socket-based interface between the kernel and userspace, used chiefly to query and configure network interfaces and routes. The kernel accumulates replies to netlink requests in a writer buffer, which it replaces with a larger one when a reply does not fit. When a reply message outgrew its buffer, nlmsg_refill_buffer() in sys/netlink/netlink_message_writer.c allocated a larger buffer and copied the partially written (unfinished) message into it. The new buffer was sized for the data about to be added, but not for the part of the message already written, so the caller could write past its end. For example, a 20-byte message plus an 8176-byte attribute received an 8192-byte buffer for 8200 bytes of data. An unprivileged local user, including one confined to a jail, can overflow a kernel heap buffer, potentially escalating privileges and gaining full control of the system. No workaround is available.

Affected Versions

kernel/netlink
